10. HTTP AND HTTPS - The Language of the Web

--> HTTP METHODS:

I.   GET    (RETRIVE THE DATA)
II.  POST   (SENDING THE DATA)
III. PUT    (UPDATE THE DATA)
IV.  DELETE (DELETING THE DATA)
V.   PATCH  (PARTIALLY UPDATE THE DATA)

--> HTTP STATUS CODE:

OK -> 200
CREATED -> 201
MOVED(URL REDIRECTED) -> 301
BAD REQUEST -> 400
UNOTHORIZED -> 401
FORBIDDEN -> 403
NOT FOUND -> 404
SERVER ERROR -> 500
